Firmware v1.0.0 · ESP32

WooCommerce Soundbox

Speaks every new order from your online store, like a UPI soundbox: “New order received of rupees 1499”. No plugin and no code on the website, only a read-only API key.

Your browser can't flash devices. Open this page in Chrome or Edge on a computer. Flashing needs a secure page. Open it from the https:// GitHub Pages address.

Connect the ESP32 with a USB data cable first. Works in Chrome and Edge on Windows, macOS, Linux and ChromeOS.

Supported board

BoardESP32 Dev Module (classic ESP32, 4 MB flash)
ChipESP32 (ESP32-D0WD / WROOM-32)
DisplaySSD1306 128×32 OLED, I2C
AudioMAX98357A I2S amp + 4–8 Ω speaker

Not for ESP32-S3, C3 or C6 boards.

Wiring

OLED SDA / SCLGPIO 21 / 22
OLED VCC3V3
Amp DINGPIO 27
Amp BCLK / LRCGPIO 26 / 25
Amp VIN5V (+ 470–1000 µF cap)

1. Make a read-only API key

  1. WordPress → WooCommerce → Settings → Advanced → REST API.
  2. Click Add key, give it a name, set Permissions: Read.
  3. Copy the ck_… key and cs_… secret. The secret is shown only once.

2. Flash the board

  1. Plug the ESP32 in with a data USB cable.
  2. Click Flash Firmware and pick its port (COM…, CP210x or CH340).
  3. Click Install, keep Erase device ticked the first time.
  4. Wait for Installation complete, then unplug and replug.

3. Set it up from your phone

  1. The OLED shows SETUP MODE. Join Wi-Fi Woo-Soundbox, password soundbox.
  2. The setup page opens (or go to 192.168.4.1).
  3. Enter your 2.4 GHz Wi-Fi, the store URL (e.g. https://yourstore.com/), the key and the secret.
  4. Tap Save. It restarts, beeps, and starts watching for orders.

Orders that already exist when it starts are remembered, not announced. Only new orders after that are spoken.

Before you flash

  • Use a Read-only API key. The key can still read customer details, so never share it.
  • Erase device wipes the saved Wi-Fi and store settings.
  • Close the Arduino IDE Serial Monitor and any other program using the port.
  • On shared hosting, a 10 s check is fine. Don't make it faster: it can slow your website.

Using the soundbox

  • New order: OLED shows #4521 Rahul and Rs.1499, the LED lights, and it says “New order received of rupees 1499”.
  • Voice not available: it beeps twice instead.
  • Hold BOOT for 10 s while running: erases all settings and opens setup again (countdown on the OLED).
  • Expect the announcement about 5–15 s after the order, because it checks the store on a timer.

Troubleshooting

No port appears in the list
  • Try another USB cable. Many cables are charge-only.
  • Install the USB driver for your board's chip: CP210x or CH340.
  • Use a USB port directly on the computer (no hub).
"Failed to connect" or it gets stuck connecting
  • Hold BOOT, press and release EN/RST, then release BOOT. Click Flash Firmware again.
  • Close the Arduino IDE, Serial Monitor or any app using the port.
  • Unplug the amplifier's VIN while flashing if the board keeps resetting.
Setup page says "The store rejected the API key"

The key or secret is wrong, or the key has no Read permission. Make a new key under WooCommerce → Settings → Advanced → REST API and enter it again.

Setup page says "Store not found (HTTP 404)"

Check the store URL. Use the home page address with https://, e.g. https://yourstore.com/. Permalinks must not be set to “Plain” in WordPress.

No order is announced
  • Only orders in Processing status are spoken (COD and paid orders). Pending payments and abandoned carts are not.
  • Orders placed while the box was off are not announced after it restarts.
  • OLED blank? Check its wiring: SDA 21, SCL 22, VCC 3V3.
It keeps restarting

Usually power. Use a good cable and charger, check for loose wires, and add a 470–1000 µF capacitor across the amplifier's VIN and GND.
